# Home banners

Assets definitivos para la Home V3. Mantener el foco visual dentro del 40 % central para que el mismo fichero sobreviva al recorte desktop/mobile.

Tamaño recomendado de exportación: 2400 × 900 px (o proporción panorámica equivalente), WebP optimizado.

Nombres canónicos:

- `manecillas-home-banner.webp`
- `samuel-home-banner.webp`
- `memoria-tierras-norte-home-banner.webp`
- `herramientas-home-banner.webp`

No incrustar títulos ni subtítulos dentro de la imagen: el texto se renderiza en HTML.
