06

Disclosure

Ver criterios técnicos de esta muestra

El contenido principal permanece visible. Este patrón se reserva para notas, condiciones o información secundaria que puede ocultarse sin perjudicar lectura, SEO ni tarea.

  • El resumen explica qué se abre.
  • No sustituye una sinopsis, una biografía ni el cuerpo de un artículo.
  • Funciona sin JavaScript.

07

Stress

Este título deliberadamente largo comprueba que la composición admite varias líneas sin truncar información significativa

La prueba termina bien si a 320 CSS px, 200 % de zoom y con aumento de espaciado de texto no aparece scroll horizontal accidental, no se recorta ningún label y el orden de foco sigue siendo lógico.
