Uso responsable

Cómo verificar una afirmación

  1. Comprueba primero la página oficial del autor, libro, premio o entidad.
  2. Para datos editoriales, contrasta con la editorial; para premios, con el organizador.
  3. Usa los JSON de prensa para reutilización estructurada y llms.txt / llms-full.txt para contexto machine-readable.
  4. Si dos fuentes difieren, no completes el hueco por intuición. Prioriza la fuente primaria y deja constancia de la discrepancia.
