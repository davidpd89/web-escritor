## Evidencia directa

- `editorial-facts.json` mantiene para Las manecillas del recuerdo `purchaseUrl: null`; hechos editoriales como PVP 16 €, editorial y fecha no constituyen una oferta comercial propia.
- La página de Samuel ofrece «Solicita información para recibirlo firmado», que es una vía manual de información/contacto, no un checkout ni evidencia de stock/fulfillment permanente.
- El repo no demuestra permiso contractual de venta directa de Manecillas, stock controlado, embalaje/envío, devoluciones ni proceso fiscal/operativo completo.

## Escalera correcta

1. sin oferta propia mientras los gates anteriores no estén verificados;
2. enlace a destino externo real cuando exista y esté verificado;
3. solicitud manual controlada solo si existe un proceso operativo real que pueda cumplirse;
4. checkout/carrito propio únicamente si el volumen y la operación lo justifican.

No capturar tarjetas directamente ni publicar stock, entrega, firma o disponibilidad que no se pueda garantizar.

## Cierre

K.1 no es un problema de HTML pendiente. Es una capacidad comercial dependiente de derechos y operación externa. La web no debe adelantarse a esos hechos.
