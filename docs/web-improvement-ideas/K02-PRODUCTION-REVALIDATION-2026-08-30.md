## Veredicto

`DEFER · NO_VERIFIED_BUNDLE_PRODUCT · NO_STOCK_OR_FULFILLMENT · NO_HYPOTHETICAL_OFFER`

Un bundle requiere un producto real, no una composición de ideas. Antes de cualquier landing/oferta deben estar verificados:

- contenido exacto del pack;
- derechos/permiso para cada elemento;
- unidades/stock;
- coste y PVP;
- embalaje/envío;
- devoluciones/soporte;
- responsable operativo;
- demanda que justifique mantenerlo.

La solicitud manual de información para un ejemplar firmado de Samuel no acredita ninguna de esas condiciones para un bundle. Del mismo modo, los datos editoriales de Manecillas no prueban disponibilidad de producto propio.

Si algún día existe el producto, preferir primero una plataforma externa o una operación manual acotada antes de construir carrito propio.

No crear mockups comerciales, Offer schema, precios ni claims de disponibilidad de un bundle hipotético.
