# Tracking — Booksprout

Objetivo: evaluar Booksprout como plataforma de ARC/reseñas para Las manecillas del recuerdo y próximos lanzamientos.

## Revisar
- Soporte real para libros en español y lectores relevantes.
- Costes, límites, políticas de reseñas y plataformas destino.
- Protección/distribución de copias ARC.
- Encaje con derechos/editorial Monza.
- Si aporta valor, preparar alta y campaña; si no, cerrar como NO-GO documentado.

## Cierre
GO/NO-GO, coste, proceso, idioma/audiencia, materiales y riesgos.
