# Tracking — NetGalley

Objetivo: evaluar si NetGalley puede aportar reseñas, visibilidad y contactos con libreros, bibliotecarios, medios y lectores profesionales para Las manecillas del recuerdo y/o futuras obras.

## Revisar
- Comprobar si Monza Ediciones ya trabaja con NetGalley o un co-op.
- Buscar a David Porto Díaz, Samuel entre mundos y Las manecillas del recuerdo.
- Revisar opciones para autores/editoriales, precios, idioma español, plazos y condiciones.
- Valorar uso postlanzamiento frente a futuros lanzamientos/ARC.
- Definir qué materiales serían necesarios: EPUB/PDF, portada, sinopsis, bio, links, territorio.
- No contratar nada sin evaluar coste/beneficio y coordinación con editorial.
