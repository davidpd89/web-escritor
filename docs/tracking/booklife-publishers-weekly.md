# Tracking — BookLife / Publishers Weekly

Objetivo: evaluar BookLife y las vías de reseña de Publishers Weekly para obtener una reseña editorial externa con potencial de autoridad y sindicación.

## Revisar
- Elegibilidad de Las manecillas/Samuel según edición y editorial.
- PW review consideration vs BookLife Review pagada.
- Coste actual, idioma aceptado, tiempos y materiales.
- Qué se publica/sindica si la reseña se hace pública.
- Comparar con Kirkus/Readers' Favorite/NetGalley antes de pagar.
- Coordinar envío de EPUB/PDF con derechos editoriales.
