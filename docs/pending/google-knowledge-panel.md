# Google Knowledge Panel

Objetivo: comprobar si Google muestra un panel de conocimiento para David Porto Díaz y, si existe, reclamarlo/verificarlo gratuitamente y corregir datos mediante las vías oficiales.

## Por qué merece la pena

Google permite reclamar gratis paneles de conocimiento de personas/entidades y verificar la representación mediante propiedades oficiales como Search Console, YouTube o perfiles sociales. Un panel correctamente reclamado ayuda a consolidar identidad, obra y fuentes oficiales en el Knowledge Graph.

## Tareas

1. Buscar `David Porto Díaz` en Google con sesión autenticada y en incógnito.
2. Confirmar si existe Knowledge Panel/entidad diferenciada y si aparecen homónimos.
3. Si existe la opción `Reclamar este panel de conocimiento`, ejecutar el flujo oficial usando Search Console u otra propiedad oficial.
4. Revisar nombre, foto, descripción, web oficial, perfiles, libros y posibles datos erróneos.
5. Enviar sugerencias solo con evidencia pública verificable; no intentar forzar un panel si Google todavía no lo genera.
6. Coordinar `sameAs`/Wikidata/ORCID/Goodreads/Amazon únicamente después de confirmar URLs canónicas.

## Criterio de cierre

Si existe: `PANEL_FOUND · CLAIMED_OR_VERIFICATION_PENDING · DATA_REVIEWED · CORRECTIONS_SUBMITTED_IF_NEEDED`.

Si no existe: `NO_PANEL_AVAILABLE · ENTITY_SIGNALS_REVIEWED · NO_ARTIFICIAL_CREATION_ATTEMPT`.
