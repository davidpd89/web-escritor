# BookBrainz — autor, obras y ediciones

## Objetivo
Crear o corregir gratuitamente el grafo bibliográfico de David Porto Díaz en BookBrainz.

## Valor
BookBrainz es una base abierta y gratuita que separa Autor → Obra → Edición, justo lo que necesitamos para representar correctamente papel y Kindle sin mezclar ISBN/ASIN/fechas.
