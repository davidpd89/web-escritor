# Pendiente — ORCID

Objetivo: revisar que ORCID refuerce correctamente la identidad pública del autor y no contenga datos incompletos o contradictorios.

## Revisar
- ORCID actual: https://orcid.org/0009-0005-9089-3782
- Nombre público, bio/keywords si procede y web oficial.
- Enlaces a perfiles relevantes y otros identificadores.
- Obras/publicaciones que puedan añadirse correctamente sin forzar el uso académico de ORCID.
- Coherencia con Wikidata, web oficial y perfiles bibliográficos.
- Visibilidad pública de los campos que interese exponer.

## Criterio de cierre
ORCID coherente con la identidad pública del autor, enlazado a la web y sin datos contradictorios.
