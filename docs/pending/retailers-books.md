# Pendiente — Retailers y disponibilidad de libros

Objetivo: auditar dónde aparecen y se venden las obras y corregir fichas inconsistentes.

## Revisar
- Amazon España.
- Casa del Libro.
- FNAC.
- El Corte Inglés.
- TodosTusLibros (seguimiento coordinado con su PR específica).
- Google Books/Play Books.
- Apple Books.
- Kobo.
- Otros retailers/distribuidores que usen Monza o Libros Indie.

Para cada obra/edición comprobar: título, autor, portada, ISBN/ASIN, editorial, fecha, formato, PVP, disponibilidad y enlace correcto.

## Criterio de cierre
Mapa real de retailers actualizado, fichas correctas donde podamos intervenir y lista de correcciones externas enviada/documentada para el resto.
