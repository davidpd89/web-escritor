# Pendiente — DILVE

Objetivo: comprobar cómo están distribuidos los metadatos bibliográficos de las obras de David Porto Díaz en DILVE y qué debe corregir el autor/editorial.

## Revisar
- Buscar `Samuel entre mundos` y `Las manecillas del recuerdo`.
- Confirmar ISBN, autor, editorial, fecha, PVP, formato, portada, sinopsis y disponibilidad.
- Revisar materias/THEMA si están visibles o accesibles.
- Comprobar diferencias entre edición física y ebook.
- Detectar datos obsoletos o incompletos que puedan propagarse a librerías/retailers.
- Identificar quién tiene capacidad de edición: autor, Monza, Libros Indie o distribuidor.
- Preparar lista exacta de correcciones que deban solicitarse a editorial/distribuidor.

## Criterio de cierre
Metadatos correctos o plan de corrección enviado/documentado para cada obra y edición relevante.
