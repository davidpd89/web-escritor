# Mastodon — identidad verificada con la web

## Objetivo
Crear o revisar gratuitamente una presencia oficial en Mastodon y verificar la relación entre el perfil y davidportodiaz.com mediante `rel="me"`.

## Valor
La verificación de identidad de Mastodon se basa en la web oficial y es gratuita. Añade otra señal pública coherente de identidad y una superficie de descubrimiento social sin pagar por verificación.

## Pendiente
- Elegir una instancia estable si no existe cuenta.
- Configurar nombre, bio, foto y enlace a davidportodiaz.com.
- Añadir desde la web el enlace recíproco `rel="me"` requerido.
- Confirmar que la web aparece verificada en el perfil.
- Valorar `fediverse:creator` para atribución de artículos si encaja con la implementación actual.

## Restricciones
Solo gratuito; no crear cuenta si no se va a mantener mínimamente.

## Cierre
`PROFILE_READY · WEBSITE_VERIFIED · IDENTITY_COHERENT · AUTHOR_ATTRIBUTION_EVALUATED`
