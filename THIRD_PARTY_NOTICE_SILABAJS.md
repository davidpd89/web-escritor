# Aviso de terceros — SilabaJS 2.1.0

El prototipo «Analizador de legibilidad en español» utiliza una adaptación mínima del algoritmo de SilabaJS 2.1.0 únicamente para el conteo silábico en español.

Proyecto original: https://github.com/nicofrem/silabajs
Autor: Nicolás Cofré Méndez
Licencia declarada por el proyecto: MIT
Versión revisada: 2.1.0

La adaptación propuesta se distribuye conservando el aviso de copyright y licencia MIT dentro del archivo `silabajs-lite-2.1.0.js`. Este documento existe además como inventario de dependencia para futuras actualizaciones.

Antes de actualizar la versión vendorizada:
1. revisar changelog/código y licencia;
2. ejecutar los casos de humo silábico;
3. comprobar de nuevo las fórmulas con textos conocidos;
4. no sustituir el archivo por una dependencia CDN.
