Herramienta gratuita para escritores

Previsualiza cómo presentas un libro antes de publicar la página.

Genera un bloque básico de metadatos para una ficha de libro y comprueba de forma orientativa el título, la descripción y la tarjeta social. No rastrea tu web ni envía los datos a un servidor.

  1. Rellenalos datos reales del libro y de su página.
  2. Revisalos previews y los avisos antes de publicar.
  3. Copiael bloque HTML y revísalo en tu web.
El preview muestra la referencia, pero no descarga la imagen indicada.

Los datos se procesan en tu navegador.

    Qué significa «preview» aquí
    
      
    Google genera enlaces de título y fragmentos automáticamente y puede usar fuentes distintas del <title> o la metadescripción. Las redes también pueden recortar o presentar las tarjetas de forma diferente según el cliente. Esta herramienta sirve para detectar problemas antes de publicar y producir metadatos coherentes, no para prometer un render exacto.
