Herramienta gratuita

Publica un evento sin descoordinar web, schema y calendario

Para presentaciones, firmas y encuentros presenciales confirmados. Un mismo formulario genera contenido visible, JSON-LD Event y un .ics.

No uses esta herramienta para fechas tentativas. Google exige que los datos del evento describan con precisión nombre, fecha y ubicación; el código generado debe publicarse en una URL dedicada al evento.

Privacidad: los datos del evento se procesan en tu navegador. No se envían a un servidor.
